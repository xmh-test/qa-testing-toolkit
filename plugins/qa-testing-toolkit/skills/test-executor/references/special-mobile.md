# 移动端专项执行参考

仅在本专项明确纳入后读取和执行，不因目标平台包含Android/iOS自动启用。普通业务功能的移动端执行仍属于常规多平台覆盖。本参考不替代原用例或授予ADB、系统设置修改、锁屏解锁权限。

## 准备与范围

- 冻结实际设备型号、系统/客户端构建、真机或模拟器、屏幕方向/显示缩放、前后台状态以及网络路线；只覆盖已纳入的系统和设备，不把Android结果外推iOS。
- 验证Computer Use/scrcpy或已授权ADB能截图、点击、输入、滑动；保存控制链路与恢复方式。iOS无可用控制入口时记录具体资源缺口，不模拟成已执行。
- 记录Wi-Fi/蜂窝、系统权限、通知、电池优化、旋转和锁屏策略等本轮会改动的基线，明确允许切换哪台设备。不要修改用户禁止的本机网络。
- 测试锁屏、系统认证前确认可恢复解锁；无法无人值守完成时单列人工步骤。不得绕过指纹/密码，不为测试关闭安全保护。

## 按纳入用例执行

| 场景 | 构造与核验 | 必需证据/判定限制 |
| --- | --- | --- |
| 前台→后台→返回 | 在操作提交前、处理中或成功后分别切换，返回后核对页面、实际对象及重复提交 | 阶段、时间、前后UI；仅切后台不证明请求被取消 |
| 锁屏/唤醒 | 先证明传输或业务尚未结束，再锁屏；解锁后核查任务及产物 | 锁屏前进度/请求、恢复后结果；开始前已完成不能算覆盖 |
| Wi-Fi/蜂窝切换 | 在已授权手机上切换，核实实际出口及请求路线，按用例核查重试/续传 | 切换前后网络、实际请求、完整产物；换网本身不证明断流 |
| 中断与恢复 | 先验证注入真正命中指定阶段，再观察提示、重试、服务端状态 | 注入阶段、对象状态、唯一新产物与SHA；不以HTTP200或文件大小替代完整性 |
| 权限与系统交互 | 仅测试产品实际需要且已纳入的文件/通知等权限，以及授权、拒绝、重返流程 | 原权限、真实系统弹窗和业务后果；不为凑场景索取无关权限 |
| 屏幕、键盘与手势 | 按矩阵验证旋转、键盘遮挡、返回、长列表选择及恢复 | 真实设备截图/操作路径；纯外观判断需已确认设计依据 |

网络、后台、锁屏、下载由浏览器或系统承担时，记录责任边界和实际承载组件；不把所有平台行为直接归为客户端缺陷。未知后台/重试策略先记录观察及规则缺口，不自行规定必须持续执行。

## 交还

恢复本轮修改的网络、权限、旋转/显示、调试端口转发、代理和电源配置，按主技能暂停/结束恢复流程执行。停止本轮辅助工具后实际重新打开业务页面并核验连接；认证受阻时明确报告，不能声称已交还。保留必要日志与证据，不删除用户原有照片/下载或关闭无关应用。

# 测试用例导出 Excel

以用户指定 JSON 为唯一明细来源，不从总结重建数据，不改变标题、数据或用例顺序。
多个候选文件无法按用户所指模块和批次确定时询问，不跨项目取最新文件。

使用本技能内置脚本，绝对路径从技能位置解析，不能假设当前目录为技能根：

```bash
python3 <本技能目录>/scripts/json_test_cases_to_excel.py <输入.json> -o <输出.xlsx>
```

默认同目录同名 `.xlsx`；用户指定路径优先。本脚本依赖同插件生成器中的共享数据校验模块，随插件一起分发。无需调用其他表格引擎或重新生成工作簿。

V3 输出 14 列：序号及 13 个用例字段。V2 纯常规用例输出同样的业务与追溯列；V1 输出序号及原 9 字段。数组以 `|` 分隔。旧版混合资产明确报错，保留输入，不静默过滤用例。

写入前验证结构；临时写入后校验 ZIP、XML、行数、列数和单元格内容，再替换目标文件。失败保留已有 Excel。不生成额外检查数据文件。

Excel 保留换行、首行冻结、筛选和列宽。交付说明输入数量、导出数量、输出路径与警告。导出检查只证明转换完整，不代表需求覆盖或业务评审已通过。

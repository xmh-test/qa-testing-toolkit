# 移动端场景扩展

先区分原生客户端、嵌入网页和移动浏览器，确认本次平台/页面及任务归属。布局适配不能替代生命周期、网络和输入风险；不从画板尺寸推定OS、横屏或平板支持。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| MOB-01 | 确认前/请求受理后/终态后切后台再回来 | 未提交不自动执行；当前目标、已受理结果和界面对应；各阶段分别选择有意义样本 | 本地/服务端任务继续、暂停/终止、是否恢复原页/弹窗 |
| MOB-02 | 熄屏/锁屏后解锁；需要时与后台路径分别取样 | 不误提交、重复执行或将旧状态当新结果，受保护数据和身份不串用 | 熄屏任务策略、省电限制、锁屏隐私与后台权限；切后台已确认不自动证明熄屏也已确认 |
| MOB-03 | 系统回收进程、手动结束应用、重新启动 | 区分新会话与旧任务，恢复后核对真实结果及原数据，未确认意图不自动重放 | 强杀/回收的差异、续跑、登录恢复、草稿与历史记录；不用重启手机代替进程回收 |
| MOB-04 | 弱网、短时断网、Wi-Fi/蜂窝切换、恢复可达、旧通道错误晚到 | 选择实际请求路径，确认当前请求/目标、无盲目重放、恢复后新操作可判定 | 远程路径/代理、自动重试、离线缓存、任务续传；延迟/丢包仅样本，不是产品SLA |
| MOB-05 | 来电/系统弹窗/系统分享打断，虚拟键盘覆盖输入，系统返回手势 | 未确认不被焦点/返回事件提交，实际目标和输入不串用，已见操作可达 | 是否保留弹窗/草稿、系统返回路由、分享/键盘/权限能力；不存在的入口不强造 |
| MOB-06 | 滑动靠近按钮、快速连点、相邻卡片、遮罩外触控 | 滚动不误写，导航和危险操作不穿透，当前对象可识别 | 连点合并、手势关闭、触控尺寸标准与导航栈策略 |
| MOB-07 | 安全区、长内容/字体变化、旋转/屏幕尺寸变化（已支持时） | 已纳入页面关键内容/操作可达，平台专有导航/全屏页按设计处理 | 支持设备/OS/方向/字号与视觉容差；不可由一张稿宣称全部机型兼容 |

从通用判据形成的用例仍需明确实际触发、恢复入口和观察结果，不写“前后台/熄屏一切正常”。选取会改变机制的代表，不能用一次切后台代替锁屏、回收和换网。多个扩展命中同一条件只保留一份用例；服务端/网络细节由C/S扩展补充。这里只做测试设计，不操作真实手机设置。

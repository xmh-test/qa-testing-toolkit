# 部署、依赖与版本场景扩展

用于已有安装/升级/运行资源或依赖约束能力；可为本地安装或远端部署，不限定容器。实际有容器/镜像时才选相关样本；普通文件下载不等于安装部署。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| DEP-01 | 全新安装、已有安装包/镜像但无实例、部分资源残留、外部删除 | 包存在不等于部署完成；本次对象/版本/配置/必要业务结果与清单一致 | 复用、覆盖/修复、残留清理、重复实例规则 |
| DEP-02 | 下载/校验/创建/启动阶段分别失败；磁盘/配额/内存不足、端口冲突、挂载/认证/架构错误 | 按真实阶段选不同故障样本，实际失败不冒充可用，保护原数据/非目标；恢复后核验新操作 | 自动清理/重拉/修复及固定文案、资源阈值；观察待准备不省略判据 |
| DEP-03 | 依赖缺失、全满足/部分满足、共享依赖已有使用方、单项或部分失败 | 满足已知配置的真实依赖对应本次目标，主功能不以部分依赖成功判全部可用 | 先后顺序、已有版本不合规时升级/拒绝、共享变更、回滚/保留、重试复用 |
| DEP-04 | 已声明约束的包含/排他上下界、精确值、多位数字、组合/非法格式 | 先取得实际支持语法和版本样本，再检查边界两侧、实际构建与声明是否一致 | 比较语义、支持格式、历史版本求解、选版优先级；不默认SemVer、仅三段或latest合规 |
| DEP-05 | 多级/共享依赖、配置变化/下架、停止的依赖、部署成功但业务未就绪 | 选择已支持的拓扑，真实业务与资源核验分开，部分结果/重复处理可追溯 | 传递/循环支持、规划读取时点、去重、自动启动/修复及就绪规则 |
| DEP-06 | 升级重复提交、处理中离开、失败后重试、完成后立即重启/重装、重进/重登 | 绑定当前版本与操作，旧错误/进度不覆盖新结果，保留范围内数据可回读 | 确认方式、仲裁、回滚、任务归属/续跑、迁移退回及恢复时限 |
| DEP-07 | 外部启停/删除、局部实例停止；共享资源的卸载/删除竞态 | 资源真实性、非目标保护及已明确保留数据边界；日志/界面不将旧资源当新结果 | 使用中定义、级联删除、应用级汇总状态、自动同步与可选组件角色 |
| DEP-08 | 安装/运行日志来源、失败重试后新输出、持续输出、断流重开 | 本次对象/阶段/任务来源明确，不混旧错误或泄露凭据 | 聚合、缓冲行数、清旧/留历史、重连续读和工具入口，不自定固定上限 |

关键部署/升级用例可组合资源、配置和业务回读证据，但不等于已有正常主线覆盖所有初始条件及失败机制。版本边界属于需求内风险；具体语法未明时保留候选，不将整个版本专项排为需求外。

# Web端场景扩展

用于本次浏览器功能。确认是联网应用还是离线本地工具、实际浏览器范围及是否有账号/后端；浏览器并不天然等于C/S或多租户。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| WEB-01 | 刷新、返回/前进、直接链接进入、提交后刷新（入口存在时） | 不将未确认意图自动提交；实际对象、历史页面与当前结果不混淆 | 路由、草稿、刷新重提/恢复规则；不要求新增深链能力 |
| WEB-02 | 同站多标签/窗口、旧标签操作、另一标签退出登录或改对象 | 对象/会话隔离，过期内容不冒充当前结果 | 共享登录、同步、冲突与退出范围；有身份能力时结合身份扩展 |
| WEB-03 | 网络失败、旧请求晚到、页面恢复；缓存/存储内容过期（实际使用时） | 区分当前请求、旧缓存和真实结果，失败不假成功 | Service Worker、离线缓存、自动重试/同步及保留时长；纯本地工具不强加网络样本 |
| WEB-04 | 浏览器下载/上传、本地文件选择、导出文件、弹窗/外链（已支持时） | 文件内容和身份对应本次操作；取消不误提交；外链不执行危险协议 | 浏览器权限/阻止提示、支持格式/大小、保存位置、下载策略；不发明插件安装流程 |
| WEB-05 | 窗口尺寸、缩放、长内容、键盘导航、实际支持浏览器差异 | 已纳入页面关键操作可到达，已定义焦点/布局标准满足 | 浏览器/版本/断点、键盘约定及无障碍等级，不自设全套合规认证 |
| WEB-06 | 外部文本/HTML/URL、存储中的敏感信息、已认证请求过期 | 不执行不可信内容、不因异常输出泄漏会话；有账号时未授权写入被拒绝 | 信任边界、服务器鉴权及安全专项范围；不因读本文件自动开展攻击扫描 |

网页关闭只证明页面生命周期结束，不代表浏览器退出、远端任务取消或本地文件删除。移动浏览器与移动扩展按实际载体组合；不将浏览器下载完成等同内容正确。

对于已知的外部文本展示功能，“内容按数据呈现，不被当活动代码执行”是通用功能与安全底线，可设计正式用例并将隔离样本/观察渠道标待准备，不必先确认完整安全专项。导出后第三方软件的公式解释、是否改变原值或转义规则则需另有依据；不要将这两层混成一个整体待确认项。

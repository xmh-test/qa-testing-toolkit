# NAS产品场景扩展

用于已纳入的NAS设备管理、数据或应用服务。先明确目标设备身份、管理路径、实际数据/业务路径及外部服务；不能从“NAS”推定支持多设备、RAID、容器、共享协议或云代理。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| NAS-01 | 客户端能管理设备但设备不能访问外部目录/下载源；反向公网条件；目录、图片、业务端口单独失败 | 记录真实请求主体和路径；失败不冒充有效空集合，资源与数据不因外部失败被清除 | 谁请求外部服务、缓存、代理、自动刷新；未知时先确认路径，不固定某一端成功/失败 |
| NAS-02 | 同设备切换网卡/AP或地址变化后重连；旧IP被另一设备占用（支持此连接能力时） | 当前连接和操作属于真实设备，旧地址/响应不认作当前结果 | 发现/认领/远程管理流程、可信身份依据及地址更新策略；探测算法全面验收不自动纳入 |
| NAS-03 | 管理断而业务通、业务断而管理通；单个服务端口失败 | 分别判断管理、设备资源、业务结果和非目标服务，不把一个故障扩大成全设备失败 | 自动诊断、端口探活、业务代理与修复能力 |
| NAS-04 | 同设备其他授权用户/端修改对象；支持多设备时切换目标、任务号相同或旧事件晚到 | 核对设备+对象+操作身份，列表/日志/重试不串用 | 多设备、账号、共享和并发能力；按需再读身份扩展，不能因NAS名称推定全部支持 |
| NAS-05 | 容量/配额不足、挂载路径不可达、共享目录权限变化、局部资源残留 | 对本次实际存储能力选择故障，记录部分结果、原数据与非目标保护；恢复后验证新操作 | 配额、协议、持久化/删除范围、自动清理/重试；不强行开展拔盘/断电或阵列重建 |
| NAS-06 | 客户端离开/退出但设备已受理任务；设备或服务重新可达 | 分开核对受理事实、当前资源与客户端显示，未确认意图不能自动提交 | 任务执行归属、设备重启/休眠续跑及历史恢复；不将关窗口等同退出或设备关机 |
| NAS-07 | 已有地区/目录源设置改变，可见目录变化、保存失败或旧响应晚到 | 目录可见性与实际资源/数据归属分开；保存结果按真实读取核对 | 设置是否存在、NAS/账号/客户端作用域、配置读取时点及切区任务策略 |

与实际功能有关时再加载C/S、身份和部署扩展；必要业务回读属于集成结果核验，不等于测试第三方应用全部业务。断网、配额/权限变更或设备故障仅设计，不代表执行授权；设备重启/硬件故障只在明确范围和隔离准备下设计。

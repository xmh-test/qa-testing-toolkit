# 独立桌面客户端场景扩展

适用于独立桌面应用，区分产品内子窗口、宿主窗口、系统浏览器及进程。先识别实际窗口控制、支持OS和本地/远端工作归属，不将PC网页当桌面应用。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| DSK-01 | 拖动、调整尺寸、最大化还原、滚动到末项（实际有入口时） | 控件可达且坐标/对象不偏，布局不阻断核心操作 | 最小尺寸、缩放、支持显示器和系统矩阵；设计参考尺寸不当产品下限 |
| DSK-02 | 模态确认、父子窗口焦点、子窗口关闭、键盘取消 | 未确认不执行；背景不穿透；关闭会话不误停业务或关闭无关对象 | Esc/Enter映射、关闭顺序、焦点恢复、子窗口独立性 |
| DSK-03 | 关业务窗口、最小化/托盘、退出整个进程、重启客户端、系统注销 | 分开记录阶段和真实结果，重进不盲目重放旧写请求 | 单实例、托盘/后台继续、进程内/跨进程恢复；关窗口规则不推广到退出 |
| DSK-04 | 电脑睡眠/唤醒、系统锁屏、网络切换与恢复 | 当前身份、对象和资源可核对，旧连接不能冒充当前成功/失败 | 本地任务暂停与远端续跑、重新登录/连接策略；不直接套手机后台规则 |
| DSK-05 | 使用已支持的外部浏览器、剪贴板、文件选择/保存等系统能力 | 本次目标/内容正确，取消/系统失败不误报完成，不泄露不相关信息 | 默认程序、权限与文件覆盖规则、支持平台差异 |
| DSK-06 | 同进程多窗口、重复启动、已支持OS/多屏/DPI变化 | 共享与隔离目标明确，弹窗及核心操作仍可到达 | 是否单实例/多窗口、窗口状态保存、兼容矩阵；不假定Windows/macOS/Linux全支持 |

仅用实际提供的系统入口设计。自动更新、安装器、驱动、系统服务等不因“桌面应用”就进入本轮；有明确范围再引用相应项目资料或新增扩展。

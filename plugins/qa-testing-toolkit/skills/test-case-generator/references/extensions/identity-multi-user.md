# 身份、多用户与并发场景扩展

有身份/会话即考虑身份失效；多用户、多角色、多租户或多端共享仅按已知能力追加。仅管理员使用并不等于会话永不失效，也不自动产生普通用户可操作规则。

| 风险ID | 代表条件 | 可判定的核验目标 | 需要来源确认的部分 |
|---|---|---|---|
| IAM-01 | 确认前会话过期/退出/撤权后仍有旧入口，新请求提交 | 当前未授权写请求不改资源、不假成功，不仅依据按钮可见性 | 会话有效期、认证流程、退出范围、提示与重登路由 |
| IAM-02 | 任务已受理后身份失效、重新登录或换账号 | 原任务与新请求身份分开，日志/结果不泄露给无权会话 | 原任务继续/终止、结果可见性、重新鉴权及恢复策略 |
| IAM-03 | 已支持的两个角色/账号访问同一对象，权限变更后旧页面再读/写 | 各自被授权的对象与数据边界不串，非目标数据不误改 | 角色矩阵、共享/租户边界、普通用户业务范围；不能凭管理员限制推定所有拒绝/允许规则 |
| IAM-04 | 同一对象由两个授权操作者/端同时修改、删除后旧页继续操作 | 本次目标、当前版本和实际结果对应，不静默改错对象 | 冲突/幂等、先后胜出、锁/合并/拒绝、是否共享任务进度 |
| IAM-05 | 两用户分别处理不同对象，局部相同名称/任务号、旧事件晚到 | 反馈/禁用/日志/重试身份隔离，甲失败不覆盖乙成功及反向情况 | 全局通知与历史可见性、任务迁移、跨会话订阅 |
| IAM-06 | 支持多设备/租户/账号切换时来回切换，旧缓存/连接残留 | 最终目标、数据、操作绑定当前有效上下文，非当前对象不受误写 | 切换入口与作用域、保留/清理缓存、会话共享；能力未知先确认 |

先选择能改变结果的主体/对象/阶段代表，不穷举所有角色组合。已确认纳入普通用户路径但缺少可用账号才是准备问题；尚不清楚产品是否支持则列范围待确认，明确排除该路径则尊重范围；三者不能互换。鉴权/并发测试只做设计，不因此获取他人数据或发送越权请求。

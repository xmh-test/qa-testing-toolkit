# 平台与页面范围行为回归

用于独立试跑/人工评审，不是关键词匹配测试，也不证明连接器读取成功。输入均为合成设计资料；输出放临时目录，无需访问真实产品或写入外部系统。

| 场景与最小输入 | 应观察的决策及产物 | 不应出现 |
|---|---|---|
| 用户要求按设计写用例，仅给PC节点链接；文件目录含PC首页/详情、移动首页/详情 | 总览列四页；读取双端相关设计；页面映射FP或候选；有依据时生成双端用例并说明分别执行 | 只做PC、问都不问便排除移动、只批量加mobile标签 |
| 用户明确仅测PC；目录同上 | 总览记录移动存在且按用户限定排除，深读PC，当前覆盖结论限定PC | 强制追加移动用例或把合法排除当缺陷 |
| 顶层只有一个页面，分区含桌面/手机画板；HTML等价输入为单文件含两种响应式布局 | 识别分区/布局差异并记录来源；载体未知按未知处理；核对导航/返回等差异 | 顶层页数或HTML文件数为1就认定单平台；从尺寸猜定iOS |
| 工具只返回PC局部节点，无文件目录权限；用户无其他材料 | 保留已知设计及可判定用例，列全貌未核验及具体受限影响；请求目录/导出稿但不编造发现项 | 声称全文件只有PC或全平台覆盖通过 |
| 旧依据只含PC；本次要求按完整新版设计更新，新目录新增移动及PC错误页 | 先补总览及深读新增项，保留有效旧ID，追加平台专有目标和错误分支；评审从新目录反查 | 以已有依据跳过盘点，或为重建清单重编号无关用例 |
| 目录含当前双端、明确标记历史版本、组件库及无关产品页 | 全部进入总览并给范围判断；历史/无关项依证据排除，状态变体与重复页可分组但有定位 | 把组件库所有变体一律当业务规则，或以相邻页不自动纳入为由不盘点 |

通过标准：范围决策与用户约束一致，读取状态真实；纳入项没有无处置的遗漏，共通与专有差异可追溯；未知范围不冒称完成。逐项记录观察证据，静态格式或现有JSON单元测试通过不能替代此行为检查。
